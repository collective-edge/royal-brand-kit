House UI standard v1.0

Controls

Everything the shared layer owns, in every state it has. Buttons, links, form controls, status badges, focus, disabled and loading. Nothing else is shared: layout, cards, tables, shells and heroes are where each site earns its character, and they are built on these tokens rather than handed down.

Every control appears twice, once on the page ground and once on a band, because a control that is only ever drawn on white breaks the first time a designer puts a dark section behind it. Where a state has no dark form, the band below says so and says why.

Buttons

Three variants, three sizes. Only the filled variants carry colour, so a screen holds one loud action. Labels are sentence case at 600 in every brand. There is no text-only button: without a fill or a border it has no boundary, and a page’s quiet action is the standalone action link below.

Links

In running copy a link is the accent with a real underline, and this is what one looks like in the middle of a sentence. On Collective Edge the accent is the ink the copy is already set in, so the underline is the whole signal. Hover thickens the underline to 2px, which is a change a person sees without a colour to read.

Form controls

Label above the field, left flush, sentence case. One message per field, below the field, never a tooltip and never a placeholder. Mark the optional field rather than the required one, because a red asterisk cannot be told from an error. Fields are 16px type: below 16 iOS Safari zooms the page on focus and does not zoom back out.

Status badges

One shape, four states, no colourway invented per project. The status colour rides on the dot and the label is set in ink, so the badge means the same thing in every brand and the warning state stays legible.

On a dark band

Put .ui-on-dark on the band. One ring colour cannot serve both grounds, so the dark scope names the other and the filled button inverts with it. A field keeps its light surface: its label and its help text flip, the box does not. The destructive button has no dark form, because the stop colour has no boundary against any of the three bands, so a destructive action belongs in a dialog on the page surface.
